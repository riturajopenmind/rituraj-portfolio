# Rituraj Kumar — Recruiter-Focused SAP BTP Portfolio

Built with pure HTML, CSS and JavaScript.

## Positioning
The site is intentionally organized for SAP BTP / SAPUI5 / CAP recruiter and technical-screening use:
- clear headline and role
- recruiter snapshot
- capability mapping
- end-to-end BTP stack
- career timeline
- case-study style project presentation
- security, workflow, integration and deployment signals
- recognition and certifications
- direct contact CTA
